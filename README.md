# 学生大使团排班助手

一个完全在浏览器本地运行的月度排班网页，不依赖人工智能，也不会上传成员名单。

## 功能

- 上传 Microsoft Excel 成员名单
- 自动识别新人和老人
- 自动生成整月周末班次
- 优先覆盖不同成员
- 优先老人带新人和同工作组搭配
- 设置最低次数、最多次数、历史次数和不可上班时间
- 网页内手动换人
- 导出 Microsoft Excel 排班结果

## 使用

打开 GitHub Pages 页面，上传成员名单后设置班次和限制，点击“自动生成排班”，检查后导出结果。

成员名单只在当前浏览器中处理，不会上传到仓库或服务器。仓库中的演示人员均为虚构名称。
